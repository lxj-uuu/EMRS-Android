## 1. 产品概述

**一句话定位**：一台通过 RS-232 串口驱动物探“供电—测量—采样”仪器（EMRS-2B），在安卓工业平板上完成 **工作参数设置 → 供电/充电/自检 → 测量数据采集 → 去噪平滑/替位平均/疏密平均处理 → 曲线显示 → 多种数据文件存盘** 的野外采集软件（功能与 lx.exe 保持 1:1）。

主工作流：

```
启动(创建6窗体+Form1显示)
  → [设置] Form3 录入 图头/参数(gzcs.txt 记忆)
  → 主界面按需：
      ├─ [自检] → 发命令01 → Form2 显示 VAB/电池电压 → [返回]发命令02
      ├─ [充电] → 发命令04(目标0) → Form6 设定目标VAB→[充电]发命令04(目标) → 实时电压→“充电完毕”
      ├─ [标定] → Form5(供电测量) 供电次数→采集 v250hz/I/V2 → [数据处理]读正演文件 → 计算标定系数 → 存 bdxs.txt
      └─ [测量] → 读 bdxs.txt 标定系数 → Form5 供电N次→采集 → [处理测量数据] → [存储处理结果](*.s/*.n/*.c/*.dat)
  → [结束]退出
```

### 4.1 串口参数

### 4.2 发送帧清单（代码级，send[1..n]）

| # | 触发点 | 长度 | 字节序列 | 含义推测 |
|---|---|---|---|---|
| C1 | 自检(Form1.B1) | 6 | `A0 A0 01 01 AF AF` | 进入自检模式（无校验字节） |
| C2 | 自检返回(Form2.B1，发送2遍) | 6 | `A0 A0 02 02 AF AF` | 退出自检（无校验字节） |
| C3 | 供电开始(Form5.B4) | 8 | `A0 A0 03 03 N N AF AF`（N=供电次数，checksum=3^3^N=N） | 开始 N 次供电+测量；send[4]=3 固定（仪器内档位） |
| C4a | 主界面充电(Form1.B8) | 8 | `A0 A0 04 00 04 AF AF` | 充电命令，目标0（语义⚠见 §6.3） |
| C4b | Form6 充电(Form6.B1) | 8 | `A0 A0 04 H L (04^H^L) AF AF`；H/L=目标VAB编码 | 按目标电压充电 |
| ACK | 收到合法帧且 msg[1]≠1 时 | 16×1B | `$A5` 连续发16次 | 帧应答（代码 `for j:=1 to 16 do Comm1.write(send,1)`，send[1]=$A5）⚠为何16次待确认 |
| NAK | 帧校验失败且 msg[1]≠1 | 1B | `$AA` | 拒绝应答 |

组帧格式：帧头 `A0 A0`，随后命令字节（send[3]=命令号 01/02/03/04），命令03/04 带参数+校验，命令01/02 以 `AF AF` 直接结束。校验=相关命令字节异或。

**重发**：C1/C2/C3 由 Timer3 每3000ms 重发至多3次（C4 不重发）；见 §3.3。

### 4.3 接收处理（Form1.Comm1RxChar）——协议还原

```
OnRxChar(Count):
  comm1.read(recebuf, Count)

【阶段A】若 waiting_ack 且收到字节 $A5：
   Timer3停、waiting_ack=false、have_head=false；
   case send[3] 切换界面（见 §3.2/3.3：4→Form6；1→Form2；2→Form1；3→Form5测量态）

【阶段B】组帧（跨多次 OnRxChar，用全局 msg[]/msg_ii/have_head 累计）：
  1. 在当前缓冲中找帧头 A0 A0 → 其后字节写入 msg[msg_ii]（msg_ii 从1开始）；
  2. 当写入的 msg[msg_ii-1]=$AF 且 msg[msg_ii]=$AF（帧尾）时：
     payload = msg[1..msg_ii-2]
     checksum = 对 payload 全部字节 XOR
     if checksum ∈ {0x00, 0x80}：
        if msg[1]≠1 → 发ACK($A5×16)
        case msg[1]（帧类型）处理（下表）
     else：
        if msg[1]≠1 → 发NAK($AA)
     exit（本帧处理完）
```

**帧类型处理**

| msg[1] | 帧内容(消息体) | 处理/公式 |
|---|---|---|
| 1（自检状态） | msg[2..5] | VAB=`((msg[2]&3)*256+msg[3])/1023*50`；电池=`((msg[4]&3)*256+msg[5])/1023*50.45`；更新 Form2 Edit1/TrackBar1/Edit2；`data_come=true`；不须回ACK |
| 4（充电状态） | msg[2..3] | VAB 同上公式；更新 Form6 Edit1/TrackBar1；`vab≥Edit2目标` → “充电完毕 !”焦点退出；`data_come=true`；不须回ACK |
| 2（供电数据帧） | msg[2]=供电次数gdcs；其后依次 250×2B(v250hz)、4×2B(I)、1200×2B(V2)；末尾校验字节 | 详细处理见下方 |

**msg[1]=2 数据帧解析步骤（输入→处理→输出）**

输入：`gdcs=msg[2]`（应=上次+1，>gdcs+1 提示“数据有丢失！”）。

1. **v250hz（前250对字节，去50Hz参考）**：
   每点 `h=msg[i], l=msg[i+1]`：
   ```
   x  = (h and 63)*256 + l            // 14位幅值
   if (h and 32) ≠ 0 then xy = -( ( (x or 0xC000) xor 0xFFFF) + 1 )   // 等价 xy=x-16384，14位补码
                       else xy = x
   v  = xy / 8191 * 10000000          // 归一到 ±1e7
   sgn = h and 192                    // 增益位
   if sgn=0   → v = v * 1
   elif sgn=192 → v = v / 16384
   else      → v = v / 128
   v250hz[i]=v  (i=1..250)
   ```
2. **电流 I（4对字节 i_count=4）**：
   ```
   temp_i = ((h and 3)*256 + l) / 1023 * 100
   temp_i = temp_i * strtoint(满档电流mddl)/100 * 5/4        // mddl∈{2000,4000,8000}
   sum_i += temp_i
   modify_i = sum_i / 4
   modify_i = modify_i - 0.000068 * modify_i * modify_i       // 非线性校正
   iab_ave[gdcs] = trunc(modify_i * 倍率bl * 100)/100          // 两位小数
   sum_i_ave += iab_ave[gdcs]
   ```
   写入 StringGrid2（Cells[grid2_lie, grid2_hang]，列0..7循环→行+1，行≥4→归0）。
3. **V2（后1200对字节 v2_count=1200，所有 prg 相同）**：
   ```
   x = (h and 63)*256 + l ；符号/增益处理同 v250hz → temp_v2
   j50hz 从 2 起步，每点后+1，>250 回绕 1
   v2value[gdcs, iii] = temp_v2 - v250hz[j50hz]     // 逐点减去50Hz参考（输入→处理→输出）
   ```
4. 结束判定：`gdcs == 供电次数ComboBox2` → 状态“供电完毕；可进行数据处理。”，`ke_sjcl=true`，Timer4 停。

**数据处理算法（Form5，输入 v2value[1..exprmt_times,1..points_end1]）**

| 过程 | 输入→处理→输出 | 关键式 |
|---|---|---|
| smooth5_3（五点三次平滑+分段滤波） | v2value 整列；对每行 i、每段 k=1..5 | ① 粗去毛刺（3点中值式）：对 j=2..points_end1-1，`aaa=sum(j-1,j,j+1)-min-max`；若 `abs(v2value[i,j]-aaa)>0.6*abs(aaa)` 则替换为 aaa；② filter_no[k] 取自 lbcs2..5（k=2..5；k=1 固定1次）；找 `j` 从15起 `while v2value[i,j]/iab_ave[i] ≥ filter_bgn[k] do j++`，bgin_j=j（filter_bgn[1..5]=100,100,10,1,0.1）；若 `points_end1-bgin_j≥3 and filter_no[k]>0`，则对 j=bgin_j..points_end1-1 重复 filter_no[k] 次：`v2[j]=(17*v2[i,j]+12*(v2[i,j-1]+v2[i,j+1])-3*(v2[i,j-2]+v2[i,j+2]))/35`，写回 |
| replace_ave（替位平均） | 各供电行逐列统计 | 若供电次数=1 直接复制；否则对每 j：各次均值 ave、标准差 dlt（除以 exprmt_times-1 开方）；保留 `|v2[i,j]-ave|≤3*dlt` 的值到 rplc[]（k<2 则跳过该列直接用ave）；迭代：k 个值平均，剔除与 ave 偏差最大者（若 `dlt>|ave|*0.02`）替为 ave 重算，直到收敛 → `v2[j]=ave` |
| sparse_ave（疏密平均/成道） | v2[1..points_end] → v2i[1..points] | `k=1; v2i[1]=v2[1]`；对 i=2..points：累加 v2[k+1..k+i]（每次取 i 个）求平均 = v2i[i]；总用点数=1+2+…+points=points_end |
| normal_i | v2i | 若 average_i>0 则 `v2i[i]/=average_i`（归一为 V2/I） |

**道时间/坐标表**（由 prg_no 决定，写入 shjian[i]、ruler_h[i]；点数规律：总点数=1+2+…+points）

| prg_no | points(道) | points_end1(=points_end) | point_no | 末道时间(µs)=point_no*80 | 首道时间 shjian[1] |
|---|---|---|---|---|---|
| 1 | 22 | 253 | 242.5 | 19400 | 0.08 (ms) |
| 2 | 28 | 406 | 392.5 | 31400 | 0.08 |
| 3 | 34 | 595 | 578.5 | 46280 | 0.08 |
| 4 | 40 | 820 | 800.5 | 64040 | 0.08 |

`shjian[i]=sum/i*0.08`（按 80µs=0.08ms 递增至第 i 组中心）；`ruler_h[i]=trunc((sum/i-1)*img_w/point_no)`（i=1 时为0）。
> 注：接收端每帧读 1200 个 V2，但计算只用前 points_end1 个（其余丢弃/历史）。§ 说明.txt 亦印证采样间隔 80µs、原始点/成道道数关系。
